Privacy Policy

What If It Happens · Last updated November 12, 2026

This policy covers the "What If It Happens" publishing tool, which the owner of the YouTube channel @whatifitreallyhappens uses to upload that channel's own videos.

Who uses the tool

Only the channel owner. The tool is not offered to the public and no other person signs in to it.

What Google data it accesses

With the channel owner's permission, the tool uses the YouTube Data API scopes youtube.upload and youtube to upload videos, set thumbnails, set titles, descriptions and tags, schedule publishing, and read the status of the channel's own videos.

How the data is used and stored

The access token is stored as an encrypted secret in the owner's private automation environment and is used only to perform the actions above on the owner's own channel. The tool does not read, collect, store, sell or share any data about viewers or any other YouTube user, and it does not use Google data for advertising.

YouTube and Google

The tool uses YouTube API Services. By using it you are also subject to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time from the Google account connections page.

Viewers of the channel

Watching the channel's videos happens on YouTube and is covered by Google's privacy policy. This site sets no cookies and runs no analytics.

Contact

Questions about this policy can be sent through the contact details on the channel's YouTube About page.
